# PROMPT: Fix SMTP App Password Persistence, False-Positive Feedback & Command Center Canvas Expansion

---

## 1. Context & User Problem Statement

Following user testing of the newly added System Admin Hub and Invitation Email Dispatch in SavazAI:
1. **SMTP Google App Password Persistence / Overwriting Bug (`image_4391f6.png`)**:
   - In Command Center -> System Admin, when saving settings or clicking "Send Test Email", masked placeholders (`••••••••`) or empty strings overwrite the stored AES-256 encrypted password in `system_configurations.design_tokens.smtpSettings`.
   - Google App Passwords generated by Google contain 16 letters grouped with spaces (e.g., `abcd efgh ijkl mnop`). If saved with whitespace, SMTP authentication fails against `smtp.gmail.com`.
   - `MASTER_VAULT_SECRET` was passed to `savazai-backend` in `docker-compose.yml`, but was NOT explicitly passed to `savazai-console`, causing console decryption to fall back to an unaligned default secret key.
   - When clicking "Send Test Email" in `system-admin-hub.tsx`, `configOverride` sent `pass: "••••••••"`, directly overriding server-side decryption and causing Nodemailer authentication failure with Gmail (`535-5.7.8 Username and Password not accepted`).

2. **False-Positive "Email Dispatched" Feedback (`image_43a839.png`)**:
   - The UI modal or API responses were at times reporting successful delivery even when Nodemailer threw errors, or failing to highlight delivery issues transparently.
   - When an email address has a typo or SMTP authentication fails, users must receive explicit amber/red diagnostic feedback with exact failure reasons and the fallback pre-authorized onboarding URL.

3. **Command Center UI Canvas & Collapsible Navigation**:
   - Command Center (`/admin/settings`) had a fixed 2-column layout restricted to `max-w-6xl` where the sub-navigation took up a fixed width (`w-64`), squeezing complex forms, JSON editors, and the 3-sub-tab System Admin Hub.
   - Requirement: Add a smooth collapsible sub-navigation rail (`PanelLeftClose`/`PanelLeftOpen`) so the menu shrinks to an icon-only rail (`w-16`), expanding the settings panel and forms to full canvas width (`max-w-[1440px]`).
